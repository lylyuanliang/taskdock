# TaskDock 架构说明

> 状态：持续维护。系统边界、持久化数据契约或已确认的技术决策发生变化时，应同步更新本文档。

## 目标与范围

TaskDock 是一款本地优先的任务管理工具，面向个人工作、软件开发交付和日常计划。首个产品形态是运行在单台 Windows 电脑上的个人桌面应用。

已发布的 `v0.2.0` 仍是本地优先版本，不需要账户、远程服务或网络连接。当前开发分支正在交付 M4 WebDAV 同步：同步配置、凭据边界、加密快照、三方合并和冲突处理已经实现，但尚未作为正式版本发布。同步只支持 WebDAV，且首版只维护一个远端当前快照；本机 Web 门户、OpenAPI 兼容 AI 服务和 Android 支持仍属于后续扩展。

## 运行时架构

```text
主窗口 React 应用              快捷面板 React 应用
          |                                  |
          +---------- Tauri IPC -------------+
                             |
                    Rust 命令层
                             |
                  领域与应用服务
                    |       |
           SQLite 仓储   同步 Worker
             与迁移          |
                    |     WebDAV
             操作系统应用数据目录（WAL）
```

### 前端

- `src/` 保存主 React 工作区，包括导航、任务编辑器、项目、月历、搜索、主题和国际化。
- `src/quick-panel/` 保存桌面快捷面板。它是独立 WebView，但共享同一个原生应用状态。
- 前端负责视图状态和交互反馈，不直接访问数据库，也不复制业务校验逻辑。
- 英文和简体中文文案维护在 `src/i18n/`。主题通过 CSS 自定义属性表达，功能组件不内嵌固定配色。

### 原生应用

- Tauri 2 承载 WebView，并只暴露明确的 IPC 命令。
- `src-tauri/src/commands/` 解析 IPC DTO，并将领域结果映射为稳定的客户端错误。
- `src-tauri/src/domain/` 负责任务规则，包括完成、恢复、重复、标签、直属子任务、项目继承、乐观版本校验和提醒状态迁移。
- `src-tauri/src/infrastructure/sqlite.rs` 负责 SQLite 持久化。模式变更使用 `src-tauri/migrations/` 中的追加式迁移；业务表统一使用 `todo_` 前缀。

### 数据归属与可靠性

- SQLite 是唯一事实来源。当前数据库文件名保留为 `todo-app.sqlite3`，用于兼容已有数据。
- 任务和项目保存在操作系统应用数据目录中。SQLite 的 WAL 旁路文件属于一致备份的一部分，必须在应用关闭后与主数据库一起复制。
- 任务变更使用持久化递增 `revision` 拒绝陈旧写入；展示用时间戳不承担并发裁决职责。
- 提醒投递使用持久化 claim token 和过期租约。原生通知被 presenter 接受后才确认投递；失败时释放 claim，允许后续重试。
- 同步配置、状态、基线和未解决冲突保存在 `todo_` 前缀表中；WebDAV 密码和加密口令不进入 SQLite、同步快照或日志。
- 同步快照默认使用 Argon2id 派生密钥和 AES-256-GCM 加密；关闭加密时才上传明文 JSON 快照，设置页会明确提示该风险。
- 同步 Worker 在启动、任务/项目本地写入和五分钟轮询时唤醒；本地写入不等待网络，认证失败进入暂停状态，其他网络失败进入可重试状态。

### 跨窗口同步

成功的任务变更会发布 `task://mutated` 事件。主窗口和快捷面板通过该事件使相关任务数据失效，并重新加载当前视图。任何一个渲染器都不被视为事实来源。

快捷面板默认点击展开。位置和交互偏好由原生偏好设置保存，窗口拖动交给 Tauri 处理，不在渲染器中模拟。

## 扩展边界

### WebDAV 同步

同步只考虑 WebDAV，不引入服务商 SDK。当前 M4 通过 `PROPFIND`、`GET` 和 `PUT` 访问远端目录，首次上传时自动创建多级目录；同步内容是完整任务/项目快照，而不是 SQLite 文件。基于上次成功基线、本地快照和远端快照执行三方合并：不同字段自动合并，同字段修改进入冲突列表，用户可以保留本地、采用远端或创建冲突副本。

WebDAV 账号密码和加密口令通过 Windows Credential Manager 保存。同步页面只返回非敏感配置和状态，IPC DTO 不返回密码。坚果云等服务商只要提供兼容的 WebDAV endpoint 即可配置，但正式兼容性仍需在 M4 人工验收中确认。

### 本机 Web 门户

未来的 Web 门户仅供同一台 Windows 电脑使用。桌面应用继续拥有任务存储和业务逻辑，浏览器只是本机客户端，不是独立部署的云服务。当前 Vite 服务只是开发工具，不是该门户。

### AI 服务

AI 集成将作为可选的 OpenAPI 兼容服务适配器存在。它必须位于任务领域之外，需要用户明确配置，并使用有类型约束的请求和响应。AI 服务不得获得不受限制的数据库访问，也不得在没有明确应用操作的情况下修改任务。

### 移动端与其他平台

Android 计划在桌面工作流、同步边界和可移植应用契约稳定后实施。Windows 专属快捷面板和通知细节必须与共享任务规则隔离。

## 已记录决策

| 编号    | 决策                                                             | 原因                                                 |
| ------- | ---------------------------------------------------------------- | ---------------------------------------------------- |
| ADR-001 | 桌面优先、Windows 优先、单用户产品                               | 以较小安装包和无账户依赖交付主要工作流。             |
| ADR-002 | 本地优先的 SQLite 持久化                                         | 个人任务可离线使用，并由用户掌握数据。               |
| ADR-003 | React + TypeScript 渲染层，Tauri + Rust 原生层                   | 兼顾 Web UI 开发效率、原生打包能力和轻量持久化。     |
| ADR-004 | 同步协议只使用 WebDAV                                            | 保持服务商中立，并符合已确认的同步方向。             |
| ADR-005 | 主题和语言采用应用级策略                                         | 扩展视觉和语言时不需要分叉功能逻辑。                 |
| ADR-006 | 用户可见名称为 TaskDock，内部数据库文件名保留 `todo-app.sqlite3` | 避免仅因品牌调整触发本地数据迁移。                   |
| ADR-007 | 同步默认端到端加密，凭据不进入 SQLite                            | 云盘只保存不可直接读取的快照，降低共享存储泄露风险。 |

## 当前版本不包含

- 多用户协作、团队权限或托管账户。
- 远程 Web 访问或云端后端。
- AI、Android、附件和评论功能。
- WebDAV 远端历史快照浏览与回滚。
- 针对旧应用标识数据目录的自动迁移。
